NovaCart v21.4 — Seller Dashboard

Seller center එකෙන් දැන් කළ හැකි වැඩ:
1. Products → Add product: title, category, SKU, price, image URL, description,
   base stock සහ visibility ඇතුළත් කර Save product කරන්න.
2. Edit product: details/price/image වෙනස් කිරීම, shop එකෙන් hide/publish කිරීම.
3. Update stock: අලුතින් sell කළ හැකි stock ප්‍රමාණය save කිරීම.
4. Variants: option එකක් add/edit කිරීම, variant price/stock/visibility වෙනස් කිරීම.
5. Orders & shipping: order search/filter, තමන්ගේ items සහ delivery details,
   processing/packed/shipped status, courier සහ tracking number save කිරීම.
6. Your payouts: period dates තෝරා Request payout කිරීම සහ refund deductions බැලීම.

Stock changed / Reload error එකක් ආවොත්:
Checkout එකකින් හෝ වෙනත් edit එකකින් stock/details වෙනස් වී තිබිය හැකියි.
Reload latest / Reload latest values ඔබලා අලුත් values බලලා නැවත save කරන්න.
Stock කියන්නේ දැනට sell කළ හැකි units ගණනයි. Base/variant stock වෙන වෙනමයි.
Supplier-linked stock/variants supplier synchronization එකෙන් පාලනය කරනවා.

Payout request එක admin review queue/ledger එකට යනවා.
මෙම button එකෙන් bank transfer එකක් යවන්නේ නැහැ. Admin ඇත්තටම transfer කළ
පසු reference එක දාලා paid ලෙස සටහන් කළ යුතුයි.
Unpaid card orders ship කරන්න බැහැ; COD orders සඳහා තිබෙන අවසරය රැකගෙන තිබෙනවා.
