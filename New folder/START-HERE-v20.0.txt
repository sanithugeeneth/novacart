Use your existing store / Update installation
--------------------------------------------
This release includes all v19.1–v19.4 security, payment, seller, forms, payout
and catalogue corrections. Preserve your own environment configuration and
existing database. New OAuth/supplier tables and an order-item supplier snapshot
are added by this combined release. Run the database migration before starting.

After extracting the new release into its own folder, use your existing database
configuration, then run:
  npm run db:migrate
  npm start

The migration is idempotent and is required when upgrading from versions that
predate this v20.0 integration release. Keep the full assets directory beside server.js.
Open the app through its server URL, not by double-clicking index.html.
Hard-refresh your browser once after updating (Ctrl+F5).

Preview screenshots: preview/ directory
Change notes: DESIGN-v20.0.md
Validation: VALIDATION-v20.0.md

The UI was tested locally. This package does not deploy the store or configure
live Stripe, SMTP, hosting, domain or production PostgreSQL services.
