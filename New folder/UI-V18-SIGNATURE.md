# NovaCart v18.0.0 — Signature UI

A major visual redesign focused on instant first-glance impact while preserving the existing application structure and behavior.

## Visual system
- Aurora/ink marketplace palette with lime and mint accents
- Editorial oversized typography
- Glass surfaces and layered depth
- Asymmetric hero composition
- Premium product cards with responsive spotlight
- Elevated drawers, dialogs and checkout surfaces
- Stronger mobile hierarchy
- Admin visual layer remains dark and operational, with the shared premium interaction language

## Interaction layer
- Pointer-aware spotlight across key surfaces
- Existing motion and reduced-motion support retained
- Existing API/database logic is unchanged by this UI-only layer
