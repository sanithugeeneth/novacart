# NovaCart v19.0.0 — Signature UI

A visual-only storefront and customer-facing UI direction: neo-editorial commerce, sculpted paper surfaces, electric coral/violet accents, oversized typography, cinematic hover depth, and responsive motion.

The layer preserves existing markup, IDs, API calls, checkout flows, cart behavior, authentication, and database logic. It adds `signature-ui.css` and `signature-ui.js` to customer-facing HTML pages. Admin keeps its dedicated Command Center visual system.
