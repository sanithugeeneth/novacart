# NovaCart v17.2 — Next UI refresh

This release is a visual/UX refresh built on top of the existing NovaCart v17.1.0 marketplace and Admin Command Center.

## Main visual changes
- Stronger typography and spacing hierarchy.
- Premium glass/soft-surface navigation and controls.
- More expressive marketplace cards, deal cards and promotion surfaces.
- Clearer product card hierarchy and action targets.
- Refined drawers/modals and focus states.
- Dedicated account/auth polish.
- Seller/support/lightweight pages receive the same surface language.
- Admin Command Center receives a darker, denser enterprise dashboard treatment while keeping its existing features.
- Mobile breakpoints were tightened for phone-sized screens.

## Scope
This release is intentionally a UI layer refresh. Existing API routes, database schema and business logic are preserved.
